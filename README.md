# SynkGrid 🎮

A sleek, lightweight, and responsive 2-Player Tic-Tac-Toe game built for local pass-and-play matches on a single device.

Designed with a clean UI and smooth turn-based mechanics, SynkGrid lets friends and family jump straight into a quick match anytime, anywhere.

---

## ✨ Features

- **Local Pass-and-Play:** Seamless 2-player turn-based gameplay on a shared screen.
- **Smart Win Detection:** Instant evaluation of row, column, and diagonal victories or draws.
- **Responsive & Minimalist UI:** Optimized for quick play on mobile screens, tablets, and desktops.
- **Instant Reset:** Quick restart button to dive right into the next rematch.
